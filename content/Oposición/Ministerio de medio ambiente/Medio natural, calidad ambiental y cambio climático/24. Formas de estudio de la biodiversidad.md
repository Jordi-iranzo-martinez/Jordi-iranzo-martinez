### Técnicas de recolección y preparación de muestras biológicas para estudios de biodiversidad

Las técnicas de muestreo biológico son metodologías científicas estandarizadas para recolección, estudio y seguimiento de flora y fauna que permiten evaluar el estado de poblaciones y especies mediante protocolos específicos de captura, marcaje y análisis de datos.

#### Recolección

Las técnicas de recolección difieren según el grupo taxonómico. 

| Grupo taxonómico    | Técnicas                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Flora               | - **Transectos de Gentry** (0,1 ha) (inventarios de plantas leñosas)<br>- **Parcelas permanentes** (seguimiento temporal)<br>- **Colecta botánica manual** (vouchers de herbario)<br>- **Cuadrantes** (cobertura vegetal y herbáceas)                                                                                                                                                                                                                                                                                                   |
| Invertebrados       | - **Red entomológica** (mariposas, libélulas, coleópteros voladores)<br>- **Trampas Malaise**: muestreo continuo de dípteros e himenópteros<br>- **Trampas pitfall**: artrópodos terrestres (carábidos, arañas)<br>- **Trampas de luz UV / trampas de luz negra**: lepidópteros nocturnos, coleópteros<br>- **Berlese-Tullgren**: extracción de mesofauna de suelo y hojarasca<br>- **Sweeping (red de golpeo)**: artrópodos de vegetación herbácea y arbustiva<br>- **Trampas de caída con cebo (dung baits)**: escarabajos coprófagos |
| Peces               | - **Pesca eléctrica** (electropesca) en ríos<br>- **Redes de arrastre y enmalle**<br>- **Nasas y trampas**                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Anfibios y reptiles | - **Búsqueda activa diurna/nocturna** (VES: Visual Encounter Survey)<br>- **Trampas de embudo con valla-guía** (_drift fences_)<br>- **Fototrampeo** (reptiles)                                                                                                                                                                                                                                                                                                                                                                         |
| Aves                | - **Redes de niebla** (_mist nets_)<br>- **Puntos de conteo** / transectos auditivos<br>- **Playback** para especies crípticas                                                                                                                                                                                                                                                                                                                                                                                                          |
| Mamíferos           | - **Trampas Sherman y Tomahawk** (mamíferos pequeños)<br>- **Cámaras trampa** (_camera traps_)<br>- **Detección de ultrasonidos** (quirópteros)<br>- **Transectos de distancia**                                                                                                                                                                                                                                                                                                                                                        |
| Microorganismos     | - **Raspado de biofilm** (sustratos rocosos o tallos)<br>- **Núcleos de sedimento** (comunidades bentónicas)<br>- **Trampa de esporas** (hongos aeróbicos)<br>- ***Swabs* estériles** (superficies, piel de vertebrados)                                                                                                                                                                                                                                                                                                                |
Se consideran buenas prácticas la recolección de material con flores y/o frutos, tomar al menos 3 duplicados por espécimen, anotar caracteres efímeros in situ (color, olor, látex).

#### Preparación

La preparación de muestras biológicas se realiza mediante la preservación, la fijación, y la manipulación en el laboratorio.

| Ábito        | Características                                                                                                                                                                                                                                                          |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Preservación | - **Silica gel** (plantas, insectos, tejidos)<br>- **Liofilización** (conserva la estructura y permite la extracción de ADN a largo plazo)<br>- **Prensado y secado** (especímenes vegetales para herbario).                                                             |
| Fijación     | - Etanol 96% (general, ADN)<br>- Formaldehído 4-10% (histología)<br>- DMSO con NaCl saturado (tejido fresco para ADN, no inflamable como el etanol)<br>- Glutaraldehído 2,5% (microscopía electrónicaA)<br>- RNAlater (ARN y transcriptómica, con congelación inmediata) |
| Laboratorio  | - Taxidermia y montaje: isectos (alfileteo), platas (cartlia de erbario),  esqelitizació )(vertebrados)<br>- Histología<br>- Extracción de ADN/ARN                                                                                                                       |

### Técnicas de estudio de la flora y la fauna en la naturaleza

También existen técnicas de estudio en la naturaleza.

- **Flora**: transectos lineales en muestreos en campo, donde se registran todas las especies interceptadas, o parcelas cuadradas o circulares (de 1 m² a varias hectáreas según el estrato vegetal).

	Los individuos se etiquetan con chapas numeradas clavadas en la corteza o atadas a la base para el seguimiento a largo plazo. y se registran los eventos fenológicos (brotación, floración, fructificación) para entender las dinámicas poblacionales.

- **Fauna**:"captura y marcaje".


### Captura y marcaje

La captura y el marcaje es una técnica para estimar el tamaño poblacional de especies de fauna. 

Se realiza de manera sucesiva, con liberación posterior, y tras un periodo de tiempo para favorecer la redistribución aleatoria de los individuos. 

La población se calcula de acuerdo con el modelo de Petersen-Lincoln: 

**N = (M × C) / R**

*N es el tamaño estimado de la población, M los individuos marcados, C el total de individuos en la segunda captura, y R los individuos recapturados.*

El marcaje se realiza con anillas para las aves, microchips o PIT-tag subcutáneo para mamíferos y reptiles, transitores VHF/PS de radioseguimiento, marcas de pintura temporal...

Para que la estimación sea válida, el marcaje no perderse ni afectar la probabilidad de mezclado, supervivencia o captura del animal, y la población debe ser cerrada entre capturas, sin inmigración ni emigración significativa.

Cuando se realizan múltiples sesiones de captura, se emplean modelos más sofisticados, como el de Schnabel (varias capturas sucesivas), de Jolly-Seber (poblaciones abiertas: nacimientos, defunciones, migraciones...), y programas especializados que modelan las tasas de supervivencia y detección (MARK, E-SURGE...).




Los métodos de seguimiento incluyen conteos directos e indirectos: 

| **Conteos directos**                                        | **Conteos indirectos**<br>(índices de abundancia)         |
| ----------------------------------------------------------- | --------------------------------------------------------- |
| Censos totales (factibles en especies grandes y conspicuas) | Frecuencia de huellas, excrementos, madrigueras           |
| Conteos en puntos fijos o transectos repetidos              | Tasas de detección acústica (murciélagos, aves, cetáceos) |
| Censos aéreos o satelitales (grandes mamíferos, colonias)   | Capturas por unidad de esfuerzo (CPUE) en pesca           |

La tecnología aplicada abarca cámaras trampa, telemetría (GPS/VHF), bio-acústica, ADN ambiental, drones (zonas accesibles), y foto-identificación (reconocimiento individual: patrones, rayas, cicatrices...)

### Inventario y seguimiento de poblaciones y especies


El inventario y el seguimiento de poblaciones permite la toma de decisiones de conservación. 

- **Inventario**: pretende responder el tipo y número de especies en un lugar y momento determinado (¿qé a?)
- **Segiieto**: tendencias poblacionales ("¿cómo cambia?")
#### Inventario

El ivetarios pede

- **Puntual** (lugar específico acotado)
- **Regional** (paisajes o ecosistemas amplios)
- **Rápido** (acelerada, para zonas amenazadas).

- **Riqueza de especies (S):** número total de especies registradas.
- **Diversidad alfa (α):** dentro de un sitio
- **Diversidad beta (β):** diferencia de composición entre sitios
- **Diversidad gamma (γ):** diversidad total de una región.

| Diversidad | Ídices                               |
| ---------- | ------------------------------------ |
| α          | - Shannon<br>- Simpson<br>- Margalef |
| β          | - Jaccard<br>- Bray-Curtis           |

#### Segiieto:

En el seguimiento, se estudia su evolución (tamaño, estructura). 

Los parámetros que se monitorean son los siguientes: 

|            |                                                                        |
| ---------- | ---------------------------------------------------------------------- |
| Tamaño (N) | - Abundancia absoluta<br>- Abdacia relativa (índices)                  |
| Estructura | - Distribución de edades<br>- Clases de talla<br>- Proporción de sexos |

La dinámica poblacional o tasa de crecimiento (r) es el sumatorio de las diferencias entre la natalidad (b) y la mortalidad (d), y la inmigración (i) respecto a la emigración (e): 

r = (b - d) + (i - e)
