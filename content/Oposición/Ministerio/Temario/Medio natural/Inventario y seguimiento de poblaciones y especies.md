El inventario y el seguimiento de poblaciones permite la toma de decisiones de conservación. 

- **Inventario**: pretende responder el tipo y número de especies en un lugar y momento determinado (¿qé a?)
- **Segiieto**: tendencias poblacionales ("¿cómo cambia?")
#### Inventario

El ivetarios pede

- **Puntual** (lugar específico acotado)
- **Regional** (paisajes o ecosistemas amplios)
- **Rápido** (acelerada, para zonas amenazadas).

- **Riqueza de especies (S):** número total de especies registradas.
- **Diversidad alfa (α):** dentro de un sitio
- **Diversidad beta (β):** diferencia de composición entre sitios
- **Diversidad gamma (γ):** diversidad total de una región.

| Diversidad | Ídices                               |
| ---------- | ------------------------------------ |
| α          | - Shannon<br>- Simpson<br>- Margalef |
| β          | - Jaccard<br>- Bray-Curtis           |


Los métodos varían según el grupo taxonómico:

| Grupo taxonómico    | étodos                                                                  |
| ------------------- | ----------------------------------------------------------------------- |
| Plantas             | - Parcelas fijas<br>- Transectos<br>- Relevés fitosociológicos          |
| Aves                | - Puntos de conteo<br>- Transectos auditivos<br>- Redes de niebla       |
| Mamíferos           | - Trampas cámara<br>- Rastreo de huellas<br>- Transectos nocturnos      |
| Herpetofauna        | - Búsqueda por encuentro visual (VES)<br>- Trampas de caída (*pitfall*) |
| Peces               | - ElectroPesca<br>- Redes de arrastre<br>- Buceo con censo visual       |
| Invertebrados       | - Trampas Malaise<br>- Trampas de luz<br>- Barrido de vegetación        |
| Hongos y microbiota | - Muestreo de suelo<br>- Metabarcoding de ADN ambiental                 |



#### Seguimiento:

En el seguimiento, se estudia su evolución (tamaño, estructura). 

Los parámetros que se monitorean son los siguientes: 

|            |                                                                        |
| ---------- | ---------------------------------------------------------------------- |
| Tamaño (N) | - Abundancia absoluta<br>- Abdacia relativa (índices)                  |
| Estructura | - Distribución de edades<br>- Clases de talla<br>- Proporción de sexos |

La dinámica poblacional o tasa de crecimiento (r) es el sumatorio de las diferencias entre la natalidad (b) y la mortalidad (d), y la inmigración (i) respecto a la emigración (e): 

r = (b - d) + (i - e)
