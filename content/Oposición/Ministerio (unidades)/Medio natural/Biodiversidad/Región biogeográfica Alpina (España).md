
|                               | Región biogeográfica alpina                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ámbito geográfico             | Pirineos y altas montañas                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Características diferenciales | - Clima frío, con nevadas abundantes y larga cobertura nival<br>- Corta estación vegetativa (2-4 meses libres de heladas)<br>- Suelos poco desarrollados, con frecuente afloramiento rocoso<br>- Fuertes gradientes altitudinales que condicionan la vegetación en pisos<br>- Escasa influencia humana → alta conservación                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Principales ecosistemas       | - Bosques subalpinos de pino negro (_Pinus uncinata_) y abeto (_Abies alba_)<br>- Praderas alpinas y subalpinas (pastos de _Festuca_, _Nardus_)<br>- Brezales y matorrales de altura (_Rhododendron_, _Calluna_)<br>- Roquedos y canchales con vegetación pionera<br>- Lagos y turberas de alta montaña                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Principales especies          | - Pino negro (_Pinus uncinata_)<br>- Abeto blanco (_Abies alba_)<br>- Rododendro ferruginoso (_Rhododendron ferrugineum_)<br>- Lastón de puerto (_Festuca eskia_)<br>- Cervuno (_Nardus stricta_)<br>- Genciana alpina (_Gentiana acaulis_)<br>- Edelweiss o flor de las nieves (_Leontopodium alpinum_)<br>- Driade de ocho pétalos (_Dryas octopetala_)<br>- Corona de rey (_Saxifraga longifolia_)<br>- Andrósace pirenaica (_Androsace cylindrica_)<br>- Sarrio o rebeco pirenaico (_Rupicapra pyrenaica_)<br>- Cabra montés (_Capra pyrenaica_)<br>- Marmota (_Marmota marmota_)<br>- Perdiz nival (_Lagopus muta_)<br>- Quebrantahuesos (_Gypaetus barbatus_)<br>- Águila real (_Aquila chrysaetos_)<br>- Buitre leonado (_Gyps fulvus_)<br>- Lagartija pirenaica (_Iberolacerta bonnali_)<br>- Rana bermeja (_Rana temporaria_)<br>- Gorrión alpino (_Montifringilla nivalis_) |
| Espacios naturales protegidos | - Parques Nacionales: Picos de Europa, *Aigüestortes i Estany de Sant Maurici*                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
