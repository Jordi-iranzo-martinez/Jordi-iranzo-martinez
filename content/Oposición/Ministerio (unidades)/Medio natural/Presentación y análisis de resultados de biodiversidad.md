
#### Análisis

Los datos de campo se transforman en métricas interpretables:

| Índice                     | Fórmula / método           | Uso principal                 | Tipo            |
| -------------------------- | -------------------------- | ----------------------------- | --------------- |
| Shannon-Wiener (H')        | H' = −Σ(pᵢ · ln pᵢ)        | Diversidad de comunidades     | Flora · Fauna   |
| Simpson (D)                | D = 1 − Σ(nᵢ(nᵢ−1)/N(N−1)) | Dominancia de especies        | Flora · Fauna   |
| Índice de Jaccard          | J = \|A∩B\| / \|A∪B\|      | Similaridad entre comunidades | Beta-diversidad |
| Densidad relativa (Dr)     | Dr = (nᵢ / N) × 100        | Importancia de la especie     | Abundancia      |
| Lincoln-Petersen (N̂)      | N̂ = (M · C) / R           | Tamaño poblacional (CMR)      | Fauna           |
| Valor de importancia (IVI) | IVI = Dr + Fr + Abr        | Relevancia de especie vegetal | Flora           |
